# Patricio Rey y sus Redonditos de Ricota — Sitio web

Sitio web multipágina sobre la trayectoria, la producción y el universo visual de Patricio Rey y sus Redonditos de Ricota. Trabajo Práctico 2 de Informática General 2026 (UNA — Cátedra Drelichman, Paleo, Nadel, Morales).

## Tecnologías utilizadas

- HTML5 semántico
- CSS3 (variables personalizadas, sistema de temas por sección)
- Bootstrap 5.3.3 (framework CSS)
- JavaScript (vanilla)
- GSAP 3 + ScrollTrigger + Lenis (librería JS — detalle en el PDF, Parte 4)

## Funcionalidades principales

- **Galería interactiva** (`rocambole.html`): tapas de discos con modal dinámico que muestra la historia de cada obra al hacer clic.
- **Formulario de contacto con validación JS** (`contacto.html`): valida campos obligatorios, formato de email y longitudes mínimas/máximas, e informa los errores al usuario en tiempo real.
- **Postales con volteo 3D** (funcionalidad adicional, en varias páginas internas): tarjetas que se dan vuelta al hacer clic para revelar información ampliada sobre discos, integrantes y hitos de la banda.
